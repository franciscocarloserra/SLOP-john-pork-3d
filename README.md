# John Pork 3D

Browser meme game: answer John Pork's calls before they ring out, kick/slam the spam calls.

Play: https://franciscocarloserra.github.io/SLOP-john-pork-3d/

Controls: WASD move, Space (x2) jump, Shift dash, click kick (in air = ground slam).

Run locally with any static server (`npx live-server`), opening index.html as a file won't load the model. three.js comes from unpkg.
