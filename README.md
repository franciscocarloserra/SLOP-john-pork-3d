# John Pork 3D

Browser meme game: answer John Pork's calls before they ring out, kick/slam the spam calls.

⚠️ Warning: Flashing lights ⚠️

Play: https://franciscocarloserra.github.io/SLOP-john-pork-3d/

<img width="1059" height="916" alt="Screenshot_20261017_075627" src="https://github.com/user-attachments/assets/a96a9360-9990-4905-b16a-7d6ce9779b49" />

Controls: WASD move, Space (x2) jump, Shift dash, click kick (in air = ground slam). On touchscreens: left stick + jump/kick/dash buttons.

Run locally with any static server (`npx live-server`), opening index.html as a file won't load the model. three.js comes from unpkg.
